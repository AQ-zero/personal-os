FAQ

Questions you might have

Where is my data stored? Is it uploaded?

Everything lives in a local SQLite file on your machine, never in the cloud. Only when you use AI features is the relevant text sent to the model provider you configured (with sensitive info redacted before sending).

Do I need to be online?

Core capture, review and ledgers all work offline. Only AI follow-ups / synthesis / adversarial review call the model you chose. Local Ollama is supported for fully offline use.

Which AI models are supported?

GPT, Claude, DeepSeek, Kimi, GLM—switch by pasting your own key in the UI. You pay the provider directly; we add no markup.

Can I sync across devices?

No cloud sync—deliberately, for data sovereignty. To switch devices, export JSON or copy that one database file, losslessly, like moving an Obsidian vault.

Why not a habit / to-do app?

Trackers let you log but not grow. Every mechanism in Personal OS is built to compound judgment and direction: decisions get reconciled, skills need evidence, emotions become signals, and AI plays devil's advocate each week.
